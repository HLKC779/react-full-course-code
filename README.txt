WHAT'S INSIDE
A Vite + React project: the lesson components (src/lessons), the Task Tracker final
project (src/components, src/hooks, src/pages), the JavaScript refresher (refresher/)
and a Vitest test. node_modules and build output are not included.

HOW TO RUN
Needs Node.js 20+ (video: Node.js 24.21.0, npm 11.19.0). In this folder:
  npm install
  npm run dev        (open the URL Vite prints)
  npx vitest         (tests)
  npm run build && npm run preview
